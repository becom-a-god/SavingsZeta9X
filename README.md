# Simple Savings Tracker

A command-line savings tracker made in Python.

## Features
- Create account with User ID and Password
- Add money manually
- Withdraw money
- View history
- Auto-save (checks and adds when you open the app)

## Important Notes
- This is a **demo app**. All money is fake.
- Not connected to any bank or UPI.
- Passwords are stored in plain text (learning project only).
- Auto-save runs only when you open the app.

## How to Run
```bash
python savings.py
